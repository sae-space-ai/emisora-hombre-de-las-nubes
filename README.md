# emisora-hombre-de-las-nubes
Radio digital autónoma 24/7 que reproduce el catálogo musical completo del Prof. Manuel Gago Fernández (@profmanuelgago) en Audius. Incluye programación temática automática, streaming desde la API/SDK de Audius, panel de control, persistencia de estado y despliegue continuo en Vercel mediante GitHub. Stack: Next.js, TypeScript, Node.js, Audius SDK,
